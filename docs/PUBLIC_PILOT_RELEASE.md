# Love Is Hard Public Pilot v1.0

Publication date: July 29, 2026
Last updated: July 29, 2026

## Release Scope

This release is the first public pilot of the Summit Learning course experience. It includes the eight-session path, workbook, immediate tools, audio companion, facilitator plans, public guardrails, local progress, local feedback checkpoints, and a local-only pilot dashboard.

## Privacy

The static site does not send analytics to a backend. Workbook notes, session completion, checkpoint feedback, and pilot event counts are stored in the visitor's browser through local storage. A visitor may export that data as JSON from the Public Pilot page.

## Terminology Safeguards

- A feeling is real without automatically proving its explanation.
- A behavior may have caused harm even when the assumed motive is inaccurate.
- Hearing does not require agreement.
- A valid need does not make every strategy valid.
- A boundary can remain valid even when its delivery needs repair.
- Pattern recognition must not replace direct safety assessment.

## Pilot Questions

- Did readers understand what Love Is Hard was within 20 seconds?
- Which starting path did they choose?
- Did they complete Session 1?
- Where did they pause or leave?
- Did they open the workbook, tools, or audio?
- Could they explain feeling versus interpretation versus claim afterward?
- Did any passage feel accusatory, one-sided, clinical, or confusing?
- Did they understand that the framework is not a verdict about one person?
