Operations

Build an Operating Agreement

Convert recurring conflict into shared rules, review dates, and scripts before the next escalation.

Single Source of Truth

Define the rules in one place so words cannot be re-labeled during conflict.

Healthy version
We use the agreement definitions first.
Distorted version
Every fight renegotiates the dictionary.
Try this instead
Let us check the term before debating the event.
Watch for
Watch for word-games under stress.
Pause Protocol

Either person can stop a flooded conversation and return with a plan.

Healthy version
PAUSE, 20 minutes minimum, one agenda item, 15-30 minute return window.
Distorted version
Chasing, texting, proving, or punishing during the pause.
Try this instead
I am at capacity. PAUSE. We return at ___ for ___ minutes.
Watch for
Watch for a pause being treated as a new offense.
Review Date

Agreements need scheduled review so they do not become a frozen contract or a control mechanism.

Healthy version
One recurring conflict, one protocol, one review date.
Distorted version
Rules used as threats or scorekeeping.
Try this instead
We review this on ___ and change what is not reducing pressure.
Watch for
Watch for the tool becoming another battlefield.
Practice: Choose one recurring conflict. Write the need, allowed strategy, not-allowed behavior, pause script, repair gate, and review date.
