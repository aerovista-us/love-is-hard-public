# MP3 Player Selection - Love Is Hard

Review basis: local `Music/Albums/Love is hard` folder, available MP3 files, available text companions, and the public-safe teaching frame.

Goal: include songs that express difficulty, repair, boundary, capacity, and two-truth tension without over-blaming or turning the public page into evidence.

## Recommended Player Set

| Order | Track file | Teaching role | Why it fits |
|---:|---|---|---|
| 1 | `After We Learned to Hear Each Other.mp3` | Repair / hopeful model | Strongest public opener. It shows what changes when both people stop preparing for harm and start hearing each other. |
| 2 | `Head vs. Heart (5).mp3` | Processing mismatch | Good early lesson on logic and feeling colliding without making either side the whole problem. |
| 3 | `Hearing Ain’t the Same as Listenin.mp3` | Listening vs. certainty | Expresses difficulty and pressure while teaching the difference between hearing words and receiving meaning. |
| 4 | `Ain’t One-Sided (I See It Clean) (3).mp3` | Shared responsibility | Useful for two-truth framing: the pattern is not one-sided, but responsibility still needs shape. |
| 5 | `Baseline.mp3` | Baseline care / space | Strong public-safe track for the idea that respect, quiet, and space are baseline relationship needs. |
| 6 | `Two Things True (1).mp3` | Two-truth integration | Best core teaching track for holding pride, hurt, care, and limits at the same time. |
| 7 | `Peace Ain’t a Prison.mp3` | Boundary / peaceful distance | Good for teaching that peace and distance can be self-protection, not automatic abandonment. |
| 8 | `🎵 Title_ Finding the Middle (3).mp3` | Bridge-building | Strong closing/transition track for mutuality, balance, and meeting in the middle. |

## Optional With Framing

| Track file | Use carefully because | Best placement |
|---|---|---|
| `How Does It Hurt Me_ (1).mp3` | Essential interrupt-piece material, but the framing is more direct and impact-heavy. | Interrupt module only, with a note that it is about capacity cost rather than blame. |
| `Feelings Ain’t Facts.mp3` | Title is blunt and can sound invalidating without context. | Feeling vs. claim module, paired with a validation script. |
| `Proof I Care.mp3` | Expresses proof pressure clearly, but has stronger pain language. | Facilitator-led proof-pressure discussion. |
| `still counts (Remix) (Remix).mp3` | Strong two-truth endurance track, but emotionally dense. | Advanced reflection or closing discussion. |
| `Nothing Left to Prove.mp3` | Good closure song, but it moves toward ending rather than repair. | Optional final reflection, not the main teaching loop. |

## Hold Back From Public Player

These may be powerful in the private project but are too accusatory, safety-specific, confrontational, unrelated, or easily misunderstood for the public MP3 player.

| Track family | Reason to hold back |
|---|---|
| `Paint Me the Villain*` | Too prosecutorial for the public-safe teaching tone. |
| `Admit it*` / `OWN IT*` | Confession-pressure language can make the page feel like a verdict. |
| `DON’T BLAME IT ON ME*` / `Louder Than Truth*` | Strong blame framing; better as private analysis material. |
| `Spear in My Throat*` / `Title_ “Not While I’m Bleeding”.mp3` / `Morning of the Quiet.mp3` | Safety/injury-specific material should stay out of the public player unless separately cleared and heavily contextualized. |
| `🎵 Title_ “Built This Before You”*` | Strong boundary material, but too directed and accusatory for the first public release. |
| `I See It Now*` | Clear ending energy, but over-blame risk is higher than the recommended set. |
| `Say the Word*` | Appears unrelated to the relationship teaching lane. |

## Suggested First Release

Use the 8-track recommended player set, all optional tracks, plus `Paint Me the Villain.mp3` and `THE NARRATOR.mp3`.

Per owner direction, the first player release includes these without additional per-track framing.

## Player Copy Rule

For every track, use a teaching label and short prompt instead of lyrics:

- what skill the song teaches;
- what difficulty it expresses;
- what the listener should practice;
- no raw lyrics;
- no evidence framing;
- no diagnosis.
