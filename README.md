# Love Is Hard - Public Learning Module

Public-safe Summit Learning case-study page for the Love Is Hard collection.

This repository is intentionally static. It hosts an anonymized multi-page teaching system about feeling, proof pressure, hidden premises, escalation, boundaries, repair, operating agreements, and songs as non-blaming learning lenses.

The public teaching frame was reviewed and consolidated from private source material. The underlying messages, recordings, and evidence are intentionally not included in this public repository.

## Teaching Features

- Eight-session learning path: name the pieces, hear clearly, find hidden premises, recognize proof pressure, map escalation, protect boundaries, separate love from operations, and build an operating agreement.
- Public-safe Borrowed War Loop teaching with interruption and repair scripts.
- Relationship Operating Agreement concepts and Agreement Glossary terms adapted for the public site.
- Page-by-page navigation with session progress and next/back movement.
- Audio companion grouped by learning role, with every public player track connected to a lesson prompt.
- Single MP3 player with playlist selection and automatic next-song behavior.
- Modular browser-local workbook with JSON export/import and print support.
- Facilitator notes.
- SVG favicon and social sharing image.

## Regenerating Pages

Shared page structure is generated by:

```bash
node scripts/build-site.mjs
```

Run this after changing the session, song, glossary, or shared navigation content in the generator.

## Public-Safety Rules

Do not add private materials to this repo:

- no private evidence ledgers;
- no recordings;
- no raw messages or transcript exports;
- no MP3 files unless separately cleared for public release;
- no private safety incident details;
- no internal API URLs;
- no claims that Summit Learning is an external customer unless confirmed by the owner.

The current `site/audio` MP3 set is intentionally cleared for this public player. Additional songs should be reviewed before publishing.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` deploys the `site/` folder to GitHub Pages.

For first-time setup, set **Settings > Pages > Build and deployment** to **GitHub Actions**.
