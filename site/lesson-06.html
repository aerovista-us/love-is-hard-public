Session 6: Boundaries

Boundaries

Protect Boundaries and Repair Delivery

A boundary can hurt without being abandonment. Repair can include ownership without self-erasure.

10-15 minutesOutput: Boundary With ReturnAudio lens: Peace Ain't a Prison
Boundary vs Abandonment

A limit is not disappearance when it includes what stops, why, and when return happens.

Healthy version
I am pausing for 20 minutes and will return at 7:00.
Distorted version
Any pause means you are leaving me.
Try this instead
I care about you. I am stopping now so I do not escalate.
Watch for
Watch for treating capacity limits as rejection.
Split Apology

Own behavior without apologizing for having a boundary.

Healthy version
I regret raising my voice. I still needed to pause.
Distorted version
I am sorry I had a limit.
Try this instead
What I did was ___. What remains true is ___.
Watch for
Watch for apologies that buy peace by deleting reality.
Pretty Repair

Warmth, tears, promises, or affection are not repair unless the pattern changes.

Healthy version
Recognition, ownership, changed behavior, follow-through.
Distorted version
A beautiful apology that resets the same loop tomorrow.
Try this instead
What will be different next time is ___.
Watch for
Watch for repair theater without a gate.
Practice: Build a boundary with return: limit, reason, return time, return conditions, and repair topic.
